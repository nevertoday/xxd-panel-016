# 🌾 XXD Panel 016

**把每张照片转成双联、单画面，或手机／iPad／电脑／儿童手表四端壁纸套装**

</div>

## 📖 关于本项目

这是一个 **Skill**（同时适用于 Claude Code 与 Codex 等读取 `skills/` 目录的 agent）。它把每一张照片单独做成一张独立成品：

- ✅ 四种模式可选：**上下双联**、**左右双联**、**纯设计版**、**四端壁纸套装**
- ✅ 双联模式严格 50/50；纯设计版只显示设计后的版画，不显示原照片
- ✅ 可给任意画布比例或精确像素尺寸；精确像素优先级最高
- ✅ 双联中可见的照片只做轻微高级摄影调色和必要的无缝环境延展
- ✅ 变化画框把同一个主体压成**一个极小的视觉锚点**，放进大片留白
- ✅ 用**一种**运动逻辑生成动态场：坠落 / 上升 / 流动 / 扩散 / 波纹回响
- ✅ 丝网印刷、Risograph、网点、纸纤维、油墨不匀、轻微套印偏差
- ✅ 严格 **2–3 色**：照片提炼的一个主色 ＋ 暖白纸色 ＋ 少量黑
- ❌ 不是滤镜、不是照片重画、不是风格迁移
- ❌ **绝不多图拼接**：普通模式每张源图一张成品；壁纸套装每张源图四张独立文件

> 📝 完整提示词提供**中文**与**英文**两个版本。

## 🚀 使用方法

### 方式一：作为 Skill 使用

克隆这个独立项目，再把目录链接到所使用 agent 的 skills 目录：

```bash
git clone https://github.com/nevertoday/xxd-panel-016.git
mkdir -p ~/.claude/skills
ln -s "$(pwd)/xxd-panel-016" ~/.claude/skills/xxd-panel-016
```

Codex 使用独立 skills 目录时，将链接目标改为 `~/.codex/skills/xxd-panel-016`。

然后上传照片并直接提要求。未指定模式时，skill 会先询问：

> 请选择模式（回复序号即可）：
>
> 1. 上下双联（默认 3:4）
> 2. 左右双联（默认 3:2）
> 3. 纯设计版（默认 3:4，不显示原照片）
> 4. 四端壁纸套装
>    手机＋iPad＋电脑＋儿童手表，默认有文字
>
> 可同时附带尺寸；壁纸套装可按设备分别给分辨率。

选择四端壁纸套装且没有说明图片关系时，skill 会继续询问：

> 请选择壁纸关系（回复序号即可）：
>
> 1. 连贯套装（推荐）
>    先生成 iPad 定调图；其他三张参考原照片＋定调图分别重构
> 2. 四张独立
>    每张只参考原照片，构图变化更自由

连贯套装不是把一张图改成四个尺寸：iPad 定调图先通过验收，其他设备每次都同时参考原照片和同一张定调图，并针对自己的画布重新构图。不会使用 iPad → 手机 → 电脑 → 手表的串联垫图，避免误差逐张累积。定调图就是四张成品之一，不额外生成第五张。

也可以一开始就把模式和尺寸说清楚：

> 用 `xxd-panel-016` 把这几张照片各做成一张左右双联海报，尺寸 2560×1440。

成品默认存到 **`~/Desktop/xxd-panel-016/`**，并按“原图名＋模式”建立独立任务子文件夹。普通模式的文件夹只放一张最终 PNG；四端壁纸套装的文件夹放手机、iPad、电脑和手表四张最终 PNG。重复任务在文件夹名后自动增加 `-2`、`-3`，不覆盖旧结果，也不会把不同原图的成品混在一起。

再次调用始终创建新的生成任务，即使原图、模式和尺寸完全相同，也会重新生成到新的编号子文件夹。旧成品不会被自动当作参考图或本次结果；只有用户明确要求继续、编辑、复核或复用某个旧文件时才会读取它。

## 🧭 模式与尺寸

模式和尺寸是两个独立选项。尺寸优先级为：**精确像素 > 明确比例或用途 > 模式默认值**。

| 模式 | 默认画布 | 成品结构 |
| :--- | :---: | :--- |
| 上下双联 `top-bottom` | 3:4 | 原照片在上、变化版画在下，严格等高 |
| 左右双联 `left-right` | 3:2 | 原照片在左、变化版画在右，严格等宽 |
| 纯设计版 `design-only` | 3:4 | 设计后的版画铺满画布，原照片仅作为生成依据，不出现在成品中 |
| 四端壁纸套装 `wallpaper-pack` | 四种设备尺寸 | 手机、iPad、电脑、手表各一张，默认有文字 |

精确上下双联要求总高度为偶数，精确左右双联要求总宽度为偶数；skill 不会偷偷修改用户给出的奇数尺寸。纯设计版接受任意正整数像素尺寸，并直接按最终尺寸生成，不把旧的半幅作品放大。

壁纸套装默认输出手机 1440×3200、iPad 2048×2732、电脑 3840×2160、儿童手表 1024×1024。可以按设备分别覆盖尺寸。壁纸关系可选“连贯套装”或“四张独立”；两者都会针对各自宽高比重新构图并保留系统 UI 安全区，不会从一张主图机械裁切。

## 🔒 精确布局是怎么保证的

作图模型不适合负责严格分区，因此双联模式分别准备摄影画框和设计画框，再用脚本逐像素拼接；纯设计版则按最终尺寸直接生成设计画面。

```bash
scripts/compose_panel.py --plan --layout top-bottom
# → 画布 1440x1920，每个画框 1440x960

scripts/compose_panel.py --layout left-right --size 2560x1440 \
  --source photo.png --design panel.png \
  --out ~/Desktop/xxd-panel-016/IMG_4821-lr.png

scripts/compose_panel.py --layout design-only --size 2048x2048 \
  --design panel.png --out ~/Desktop/xxd-panel-016/IMG_4821-design.png
```

旧参数 `--top` / `--bottom` 仍可作为 `--source` / `--design` 的兼容别名。摄影画框对不上窗口比例时，优先延展背景而不是裁进主体；脚本会在裁得太狠时警告。

想检查手上已有的成品跑没跑歪：

```bash
scripts/compose_panel.py --audit poster.png --layout top-bottom
scripts/compose_panel.py --audit poster-lr.png --layout left-right
scripts/compose_panel.py --audit artwork.png --layout design-only --size 2048x2048
```

需要 Pillow；本机默认解释器没有的话用 `/opt/homebrew/bin/python3` 跑。

## 🎛️ 可自由调整的部分

这套提示词是**高质量起点**，不是不可变的版式规范：

| 参数 | 说明 |
| :--- | :--- |
| **🧭 输出模式** | 上下双联、左右双联、纯设计版、四端壁纸套装 |
| **📐 画布尺寸** | 可指定比例、用途或精确 `宽×高` 像素；默认值随模式变化 |
| **🎯 锚点尺度** | 默认占变化画框宽度 12%–26%；想更孤绝就调小，想更有存在感就调大 |
| **🕳️ 留白比例** | 默认 60%–78% 干净留白，可按题材增减 |
| **🌀 运动逻辑** | 坠落 / 上升 / 流动 / 扩散 / 波纹回响，可指定而不交给模型自选 |
| **🎨 配色** | 可换纸底色、指定主色、决定是否用黑，但总色数别超过 3 |
| **🖨️ 印刷强度** | 网点粗细、颗粒密度、套印偏移量都可以加减 |
| **📝 文字系统** | 所有模式默认标题与 2–4 组微型文字；只有明确要求无字时才关闭 |

### 文案如何与原图绑定

自动文案不会只看“画面里有什么”，而是依次读取表层事实、主体之间的关系张力，以及这些事实共同暗示的潜台词，再用精准命名、反差、低调陈述、双重含义或轻微反转提炼极短标题。标题必须通过“换图测试”：换到一张无关照片仍然成立，就必须重写。目标是克制、准确的“会心一击”，不强行玩梗，也不虚构原图无法证明的故事。

用户提供完整成稿时逐字保留，并按语义词组处理重音、断行、字号与位置；用户提供方向或可编辑草稿时，先理解受众、传播目的、必须保留的词、语气和潜台词，再在允许范围内专业精炼。只有歧义会实质改变意思时才追问。

文案语言优先看目标受众，而不是下指令时用了什么语言：目标市场／受众地区 > 指定成品语言 > 文案方向语言 > 当前请求语言。用中文要求“日本版”会转创为自然日语，“韩国受众”使用自然韩语，“英国版”使用英式英语。日语遵守汉字／假名比例、日文标点和禁则断行；韩语遵守空格与谚文字块；英式英语使用英国拼写、词汇、日期习惯和克制语气。不会根据人物长相或场景猜国籍，也不会用伪外文制造国际感。

## 💡 核心原则

调整时建议保留四条核心原则，动了它就不是 016 了：

1. **布局忠实**：双联严格 50/50；源图隐藏模式不出现原照片或接缝；壁纸四端分别重新构图，连贯模式以“原照片＋同一定调图”扇出而不串联
2. **一个主体 · 一种运动 · 一个巨大空间关系**，不叠特效、不加第二焦点
3. **源图与变化画框必须有清晰的身份呼应**，锚点一眼能认出来自同一主体
4. **粗粝印刷质感是必需的**，被禁止的是普通渐变、CG 光效和 3D 光滑感

## 🔁 与 XXD Panel 019 的关系

016 与 019 共用同一套执行骨架：先选四种模式之一、再定尺寸、逐图隔离、双联中的原片保护、Codex 位图生图、变化画框独立生成、壁纸安全区、脚本收口、视觉验收。壁纸套装统一输出四张、默认有文字，并提供“连贯套装 / 四张独立”关系选择；两种关系都逐设备重新构图，禁止用 SVG 或程序化绘图代替生图。

两者只保留必要的风格差异：016 的变化画框是「极小锚点 × 单一运动场 × Riso/丝网印刷」，文案在目标语言中保持极短、克制的实验艺术书气质；019 的变化画框是「可辨认主体 × 复古现代主义平面插画」，文案在目标语言中保持现代主义编辑层级。
