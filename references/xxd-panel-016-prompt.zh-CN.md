# 粗粝动态场版画 · 完整提示词（中文）

将上传的图片严格作为唯一的内容来源和摄影原片使用。每个所选普通模式都为每张照片生成一张独立成品；四端壁纸套装为每张照片生成手机、iPad、电脑、儿童手表四张分开的壁纸文件，并按调用方锁定的 `INDEPENDENT / 四张独立` 或 `LINKED / 连贯套装` 关系执行。绝不把多张照片或四张壁纸拼成一张图。

最终成品采用调用方锁定的一个或多个模式：上方摄影＋下方版画、左侧摄影＋右侧版画、只输出一张铺满画布的变化版画，以及／或输出四张分别重新构图的设备壁纸。无论选择哪些模式，版画都必须来自这张照片，而不是无关抽象画或照片滤镜。

后文统一使用**变化版画设计画框**：在上下模式位于下方，在左右模式位于右侧，在纯设计版和每张壁纸中就是整张画布。

## 零、美学动机与生成介质锁

模式和设备尺寸只能改变位置与画幅，不能改变 016 的美学动机。每个变化画框都必须清楚呈现：**这张照片里的特定主体 → 压缩成一个可辨认的小锚点 → 从其姿态、光线或空间关系推导一种运动逻辑 → 巨大纸面留白 → 真实 Riso / 丝网印刷质感 → 作为空间节奏参与构图的实验艺术书文字**。

如果换成一张无关照片，锚点、运动场、色盘和文案仍几乎不用改变，则成品是失败的通用装饰图。不得用通用圆环、太阳、波浪、山形、抽象纹样或空纸纹冒充源图转译。设备安全区只能移动构图，不能删除主体锚点、运动逻辑、印刷质感、主标题或文字层级。

所有变化画面与扩图必须调用可用的位图生图能力生成或编辑，并以 PNG 位图交付。“平面、版画、矢量般边缘”只描述视觉外观，不代表文件格式。禁止用 SVG、HTML、CSS、Canvas、图表、手写矢量代码或其他程序化绘图替代生图。应根据实际能力而非供应商名称或单个环境变量判断可用性；缺少某个环境变量不等于没有认证或生图能力。检查时只能返回脱敏状态，不得读取、展示、记录或泄露任何密钥值。用户明确调用本 skill 并提交原图与模式，已经构成对使用当前已配置位图路径完成本次 PNG 生成的确认；内置工具未暴露而切换到兼容的已配置路径时，不得再次询问。只有经过安全检查确认不存在可用位图路径后，才能说明当前受限，不能偷偷退化成 SVG。

每次调用默认都是新的生成任务。即使原图、模式和尺寸与旧任务完全相同，也必须重新生成并写入新的任务子文件夹；旧成品不能作为本次参考图、输入图或完成凭证。只接受用户当前附图、明确路径或当前请求明确指向的既有用户原图。禁止为了寻找输入而扫描桌面、工作区或本 skill 的输出目录；若原图不可访问，应请求原图或路径，不能转而复核旧成品并宣称完成。

## 一、输入图片的角色

上传图片是唯一的内容来源，同时承担两个角色：

1. **摄影区域的原片**
   在双联模式中忠实展示这张照片：上下模式位于上方，左右模式位于左侧。保持主体结构、真实质感、自然光影和原有色彩氛围，只做轻微高级调色。纯设计版和四端壁纸都不显示原片。

2. **变化版画场域的信息来源**
   分析照片中最具识别性的**主体、轮廓、姿态与叙事关系**：主体是什么、它朝向哪里、它在做什么动作、光从哪里来、它与环境构成怎样的空间关系。再把这些关系重构到变化版画设计画框中。

不得引入任何其他图片、场景、物体、颜色或象征。不得把示例作品的主题、配色或构图搬到新作品上。唯一例外是 `LINKED` 壁纸套装：通过验收的定调壁纸可以作为同一源照片另外三张壁纸的第二视觉参考，但只负责锁定视觉家族；原照片仍是主体、姿态、关系、颜色与叙事的唯一内容依据。

## 二、工作方法

方法必须是：

**DECONSTRUCT → ANCHOR SELECTION → MOTION DERIVATION → RISO RECONSTRUCT**

（解构 → 选定锚点 → 推导运动 → 版画重构）

这不是风格迁移，也不是照片矢量化，更不是照片描摹。

先在内部完成以下判断，但不要输出分析文字：

1. 找出照片中**唯一**最具识别性的主体，作为变化版画的视觉锚点。
2. 判断这个主体最本质的特征：轮廓、姿态、朝向、重心、以及它与空间的叙事关系。
3. 从主体自身特征中推导出**一种**主要运动逻辑，而不是外加特效。
4. 删除表面纹理、透视细节、背景杂讯、次要物体和一切低信息装饰。
5. 用最少的标记重建「一个主体 · 一种运动 · 一个巨大空间关系」。
6. 使变化画框第一眼是极简版画构成，第二眼才使人联想到这张特定的源照片。

源照片与变化版画之间必须存在**清晰的身份呼应**：看过源照片后再看变化场域，能立刻认出「是同一个主体」。

## 三、摄影区域（仅双联模式）

保留原始照片，不重画、不替换、不风格化、不插画化。纯设计版和四端壁纸跳过本节，原片只作为生成依据。

- 保持主体结构、真实质感、自然光影和原有色彩氛围。
- 只允许**轻微**的高级摄影调色：微调对比、控制高光、加深阴影层次、统一色温、轻微降饱和或提纯某一主色，使其接近艺术杂志和展览摄影的调子。
- 不得做重口味滤镜、HDR、强色调分离、赛博配色、过度锐化或磨皮。
- 为适配摄影画框（形状由第九节选定的模式与画布决定），可以**自然扩展天空、地面、水面或环境背景**，使构图完整。
- 扩展必须与原图光线、颗粒、透视和色彩连续一致，看不出接缝。
- 严禁拉伸、压扁、扭曲、变形或改变主体本身；严禁为凑比例做激进裁切而切掉主体的关键部分。

## 四、变化版画 · 视觉锚点

从照片中提取最具识别性的**主体、轮廓、姿态与叙事关系**，重构为超现实极简版画。

锚点规则：

- 把主体压缩成**一个**清晰而克制的视觉锚点，通常以**较小尺度**置于大片留白中。
- 默认锚点占变化画框宽度约 **12%–26%**，高度不超过变化画框高度的 **20%–30%**。极端诗意的画面允许更小，但不得小到无法辨认。
- 只保留最关键的轮廓与姿态；不要复刻复杂细节、表面材质、五官、纹样、窗格、羽毛、叶脉或机械结构。
- 锚点可以是实心色块、纯轮廓线、网点填充的剪影，或三者的克制组合，但**只能选一种主导做法**。
- 锚点位置由原照片的重心和朝向决定，通常偏离几何中心，形成非对称张力；不要默认居中。
- 不得出现第二个同等重量的主体。次要元素只能作为极小的、几乎消失的附属痕迹存在。

按主体类型自适应：

- **人物**：一个连续、不规则的剪影，头肩身体连成一体，保留姿态与朝向，不画面孔、手指和衣纹。
- **动物**：保留最具识别性的外轮廓与动势（奔跑、伫立、展翅、回头），不画毛发和眼睛细节。
- **植物**：保留生长方向与枝干节奏，不画叶片内部结构。
- **建筑**：保留一至三个身份线索（收分、拱洞、尖顶、层叠节奏、天际轮廓），不画砖石、窗户和装饰构件。
- **器物**：保留两至三个平面标记建立辨识，不画金属高光、体积感和内部结构。
- **交通工具**：保留整体外形剪影与运动朝向，不画车灯、格栅、轮辐细节。
- **自然景观**：压缩为一至两条不规则的水平轴或一个孤立地形块，保留尺度关系。

原则是：保留「最低必要辨识度」，而不是复刻物体。

## 五、变化版画 · 动态场

让原图中的动作、方向、光影或空间关系转化为围绕锚点展开的**动态场域**。

### 5.1 运动逻辑（只选一种）

根据主体自身特征自然选择**一种**主要运动逻辑：

1. **坠落**——由上而下，适合下坠、飘落、垂挂、俯冲、雨雪、瀑布类主体。
2. **上升**——沿纵向向上，适合烟、雾、飞鸟、气球、火焰、生长类主体。
3. **流动**——顺某一方向横向或斜向推移，适合风、水流、人潮、车流、奔跑类主体。
4. **扩散**——由核心向外辐射，适合光源、爆发、绽放、声响、涟漪源头类主体。
5. **波纹与回响**——不规则同心波或断续回声，适合静止但有存在感的主体、水面、共鸣、回望类叙事。

**严禁同时堆叠多种运动**。一张画面只有一个方向的场。

### 5.2 场的构造

- 使用**大量细线、断裂轨迹、粗粝网点和颗粒密度变化**表现运动。
- 密度梯度：核心附近更密、更强、更重叠；向边缘逐渐稀疏、破碎，最终消失于留白。
- 场必须与锚点在几何上相连或明确指向锚点，让人一眼看出「运动从这里来 / 到这里去」。
- 线条允许断裂、错位、粗细不匀、轻微手工抖动，不得整齐排列成规则网格或标准放射线。
- 颗粒可以溢出画面边缘并被裁切，制造场比画面更大的暗示。
- 不使用光晕、体积光、镜头光斑、景深虚化、3D 体积、投影和真实反光。

### 5.3 尺度反差

整体追求**极小主体、极大留白、强烈尺度反差**。

- 变化画框保留约 **60%–78%** 的干净留白（留白可含极稀疏的颗粒尾迹，但不得被填满）。
- 不要为了「填满画面」而放大锚点或增加元素。
- 空旷本身就是内容：安静、孤独、神秘、诗意，带轻微超现实感。

## 六、版画质感与印刷语言

变化画框必须读起来像一张**手工印刷品**，而不是数字插画。

必须保留：

- 丝网印刷（Silkscreen）与 Risograph 的质感
- 粗颗粒、网点（halftone dots）、纸张纤维
- 油墨覆盖不均、边缘毛刺、油墨堆积与缺墨
- 轻微套印偏差（misregistration）：色版之间 0.5–2mm 的错位

深浅关系必须来自**网点密度、油墨叠压与纸面留白**，而不是普通渐变。

严禁出现：

CG 感、3D 渲染、真实光效、光滑数字插画、平滑渐变、矢量纯净边缘、图层混合特效、玻璃拟态、赛璐璐动画质感、AI 通用美术风、模板感。

## 七、色彩系统

从源照片中提炼**最有辨识度、最有精气神的一个主色**，与暖白 / 象牙白 / 自然纸色，以及**少量**黑色，组成严格的 **2–3 色**体系。

- **一个主色**：来自照片中真实存在且最有生命力的颜色。可适度提纯和强化，使其鲜明、有力量，但不过度数字化、不霓虹、不荧光。
- **一个纸底色**：暖白、象牙白或自然纸色（例如 #F4EFE4 / #F0EADC / #EFE8DA 同色系），作为变化画框的背景与留白。
- **可选的少量黑**：只用于极小面积的锚点结构、断线或关键文字，绝不成为第二主色。

规则：

- 整个变化画框总色数不得超过 3。
- 不加入无来源的互补色、第二强调色、霓虹色或渐变色。
- 深浅层次通过网点密度和油墨叠压实现；两色叠压产生的第三视觉色是允许的，且是被鼓励的印刷效果。
- 变化画框背景必须是连续的纸色，可有纸纤维和轻微不匀，但不得出现渐变、暗角、光照变化或色带。

## 八、文字系统 · 实验艺术书微排版

建立克制的**实验艺术书微排版系统**。

### 8.1 文案模式与用户优先级

文案没有静默默认值。正式生图前必须明确选择：根据原图内涵创作的自动文案、用户输入的自定义文案，或完全无文字；选择自动或自定义时还必须明确目标语言或地区。每张照片在生成前分别锁定自己的文案包，按以下优先级处理：

1. **用户明确要求无文案、无字或纯视觉**：整张成品不出现任何字母、汉字、数字、标题、说明或装饰性伪文字。
2. **用户提供了可直接使用的完整文案**：逐字保留，不改写、不翻译、不增删；只调整字号、位置和排版关系。
3. **用户提供了文案创作思路、主题、语气或关键词**：按该方向创作一个确定版本，不额外输出候选方案。
4. **用户没有提供文案模式或目标语言／地区**：停止在生图之前，用一个简洁问题让用户选择自动文案、自定义文案或无文字；自动／自定义还要补充语言或地区。不得自行猜测后继续。

多张照片必须逐张建立独立文案包。用户给出的统一创作方向可以作用于整批，但除非用户明确要求相同文案，每张照片仍应根据自身内容产生不同文字。

文案语言与用户下指令的语言分开解析。自动文案或方向型文案按以下优先级确定目标语言与地区：**明确的目标市场／受众地区 > 明确指定的成品语言 > 用户方向或草稿所用语言；以上均未明确时，生图前询问**。例如用户用中文说“做日本版”，成品使用自然日语；说“韩国受众”，使用自然韩语；说“英国版”，使用英式英语；说“阿拉伯语版”，在未指定地区变体时使用自然的现代标准阿拉伯语。不得根据人物长相、姓名、服装、场景、文件名、元数据或画面招牌推断国籍、民族或受众语言。

本地化必须是转创，不是逐字翻译：保留语义核心和“会心一击”的作用，再用目标语言自然的语序、语域、习惯表达、标点和断行重新成立。阿拉伯语默认使用自然的现代标准阿拉伯语，除非用户指定地区变体；保持正确字形连写、从右到左阅读、阿拉伯语标点、按语义断行，并谨慎处理嵌入的拉丁文字或数字。只反转文字流向与排版对齐，不得不加判断地镜像源图主体和构图。日语使用当代自然表达、合适的汉字／假名比例、日文标点与禁则处理；韩语使用当代自然表达、正确空格和完整谚文字块，不用装饰性伪汉字；英国英语采用英式拼写、词汇、标点、日期习惯与克制语气，不混入美式表达。其他地区同样遵守其母语习惯。用户给出最终成稿时仍逐字保留；如果最终成稿与目标地区冲突且用户没有明确授权翻译或本地化，先问一个简短问题。

把用户输入区分为“不可改动的最终成稿”和“允许深化的方向或草稿”。最终成稿以用户原文为语义权威，逐字保留，同时理解其中的重音、转折、双关、对象和语气，再用字号、位置、留白、断行和与运动场的关系专业呈现；断行必须服从语义词组，不能拆散固定搭配、制造错误歧义或把核心词降成看不清的微型文字。方向或草稿则先锁定受众、传播目的、必须保留的词、语气和潜台词，再在用户许可范围内精炼。只有歧义会实质改变意思时才问一个简短问题，否则采用最保守、最忠实的理解。

### 8.2 语义提炼与主标题

在自动文案模式下，从照片的动作、距离、状态、情绪或隐喻中，以目标受众的自然语言提炼**一个极短标题**。016 的实验艺术书气质来自克制、尺度和排版关系，不依赖固定使用英文。用户提供成稿或创作方向时，优先服从用户的文字、目标地区与本地化授权。

写标题前，在内部完成三层阅读：

1. **表层事实**：画面确实出现了什么主体、动作、方向、距离、光线或空间关系。
2. **关系张力**：什么正在靠近、错开、等待、支撑、离开、悬停、对抗或回响。
3. **潜在含义**：前两层共同暗示的处境或情感，但不得虚构画面无法支持的人物经历、地点、归属、事件或心理。

将三层压缩成一句不对外展示的“语义核心”，再选择一种克制的修辞支点：精准命名、反差、低调陈述、双重含义或轻微反转。目标是让标题出现后，观众突然重新看懂画面，产生安静但准确的“会心一击”；不是强行玩梗、写金句或制造煽情故事。

- 英语通常优先 **1–4 个词**；日语、韩语和其他语言采用一个同样简短、自然、完整的语义单位，不为追求字数破坏语法。
- 必须对应照片中真实存在的事实或关系，不得凭空抒情。
- 执行“换图测试”：如果换成一张无关照片，这个标题仍然几乎同样成立，就说明它不属于当前画面，必须重写。
- 避免旅游宣传语、地点介绍、摄影术语，以及 "Memory" "Dream" "Moment" "Journey" 这类空泛词。
- 不得擅自编造年份；只有用户明确提供或要求年份时才保留。
- 只输出一个最终标题，不生成候选、不解释。

### 8.3 微型文字（2–4 组）

搭配 **2–4 组**微型文字，可从以下类型自由组合：

- 短句或残句（3–8 词）
- 状态词（如 DRIFTING / HOLD / NO SIGNAL）
- 地点或对象信息（克制、抽象，不做旅游说明）
- 序列号（如 NO. 016 / SER. 07）
- 坐标式数字（如 34.21 / 118.77，或 0.42 — 1.08）
- 方向词（NORTH / DOWNWARD / OUTBOUND）
- 档案标签（PLATE Ⅱ / FIG. 3 / ARCHIVE）
- 观察注释（一行极短的、像手记的观察）

以上英文例子只说明信息功能，不是固定输出语言。目标为日语、韩语或其他语言时，改写为该语言真正自然的对应表达；第二语言只能作为用户允许且语义明确的少量编辑点缀，不能使用伪外文或乱码制造“国际感”。

规则：

- 微型文字必须延续同一语义核心：补充观察、坐标感、状态或余韵，不得堆砌与标题无关的随机档案标签。
- 微型文字字号必须**远小于**主标题，形成明确的层级差。
- 全部使用无衬线或工整的等宽字体，字重轻，可拉开字距。
- 总文字量必须克制：整个变化画框的文字不得超过画面视觉重量的 15%。
- 主标题必须在正常观看尺寸下一眼可辨，视觉尺度至少约为微型文字的 3 倍；不得把主标题缩成近乎不可见的细线标签。

### 8.4 排版参与画面

文字必须**参与空间与运动**，而不是独立贴在画面上：

- 沿地平线、动态轨迹、主体轴线或留白边缘排列
- 可纵排、可旋转 90°、可大幅拉开字距（tracking）
- 可嵌入颗粒场中，被网点半掩
- 可被细线轻微穿过，或被油墨覆盖而局部缺失
- 用户原文按语义词组断行；视觉节奏不能覆盖语义节奏，核心词、否定词和转折词不得被拆散或弱化

禁止：居中大标题式海报排版、商业广告排版、模板化标题框、文字投影、描边字、渐变字、艺术变形字。

主标题颜色取主色或黑，微型文字取更浅或更低饱和的同色系。文字必须在纸色背景上可读，但不得抢走锚点的视觉中心。

双联模式的摄影画框内**不得出现任何文字**；纯设计版的整张设计画框可按文案模式排版。

### 8.5 锁定文案的传递格式

调用作图模型前，不把具体文案留给模型临时发挥。将已确定的逐图文案包以以下格式附在提示词末尾：

```text
COPY MODE: REQUIRED
COPY ORIGIN: USER_EXACT | USER_DIRECTION | SOURCE_DERIVED
COPY LOCALE: <已解析地区，例如 ar | ja-JP | ko-KR | en-GB | zh-CN>
COPY INTENT — INSTRUCTION ONLY, NEVER RENDER: <一句语义核心与预期的情绪转折>
MAIN TITLE: <锁定的准确文字>
MICROTEXT 1: <锁定的准确文字>
MICROTEXT 2: <锁定的准确文字>
MICROTEXT 3: <可选的锁定文字>
MICROTEXT 4: <可选的锁定文字>
COPY RULE: 只渲染 MAIN TITLE 与已填写的 MICROTEXT 字符串，每条恰好一次；COPY ORIGIN、COPY LOCALE 与 COPY INTENT 只是指令，绝不显示。不得改写、翻译、纠错、复制或新增文字；字形连接、标点、空格和断行必须服从目标地区语言规则。
```

删除未使用的可选行，不得渲染占位符。无文案模式用 `COPY MODE: NONE — render no text or pseudo-text anywhere.` 替换整个区块。

## 九、输出模式、尺寸与边界

### 9.1 四种模式

生成前锁定一个或多个模式；若调用方没有给出模式，先询问再继续。接受单个序号、用 `+`／顿号／逗号／空格分隔的多个序号、模式名称，以及 `全部`／`all`；去重后固定按 1→4 执行。每个所选普通模式各输出一张，选择壁纸模式再输出四张，因此“全部”每张源图共输出七张 PNG，分别放入四个同级模式文件夹，绝不合成总图。默认让同一张照片的锁定文案在所有所选模式中逐字共用；用户明确给出按模式区分的文案时才分别锁定。多选时自定义尺寸必须标注所属模式；一个未标注尺寸可能对应多个模式时，先询问，不得任意套用。

1. **TOP_BOTTOM / 上下双联**：原照片在上，变化版画在下；两区严格等高。未指定尺寸时，每区沿用源图完整 W×H，成品为 W×2H。
2. **LEFT_RIGHT / 左右双联**：原照片在左，变化版画在右；两区严格等宽。未指定尺寸时，每区沿用源图完整 W×H，成品为 2W×H。
3. **DESIGN_ONLY / 纯设计版**：原照片只作为内容依据，不出现在成品中；设计后的版画铺满整个画布，没有分界线。未指定尺寸时沿用源图 W×H。
4. **WALLPAPER_PACK / 四端壁纸套装**：同一张源照片生成四张互不拼接的变化版画壁纸，依次为手机、iPad、电脑和儿童手表；全部不显示原照片。文字遵守生图前已确认的自动文案、自定义文案或无文字选择；进入此模式时还要锁定 `INDEPENDENT` 或 `LINKED` 壁纸关系。

模式由用户意图决定，不由画布横竖方向擅自改变。双联模式必须保持精确 50/50；源图隐藏模式不得重新加入原照片、分界线或预留空位。壁纸套装必须为四个设备分别生成、分别构图，禁止把任何一张机械裁切或缩放成另外三张。

壁纸关系分为两种：

1. **INDEPENDENT / 四张独立**：四张都只接收原照片、完整 016 美学提示词、同一组锁定源图事实、色盘、运动逻辑与文案包；不把任何已生成壁纸作为参考，因此构图变化更自由。
2. **LINKED / 连贯套装**：默认先生成 iPad 定调壁纸（用户明确指定其他设备时服从用户），并在继续前检查源图身份、美学动机、文案、排版和安全区。其余三张每次都同时接收原照片与这同一张定调图：原照片锁内容与身份，定调图只锁色盘、版画语法、运动处理、排版节奏和质感。三张都直接指向同一定调图，禁止 iPad → 手机 → 电脑 → 手表式串联，避免误差累积。

`LINKED` 仍然使用四次独立生图调用、输出四张文件；定调图就是四张成品之一，不额外生成第五张主图。其他设备必须重新求解锚点位置、运动场、安全区和文字排布，而不是对定调图做尺寸转换。每次仍重复完整美学提示词与锁定文案，不能依赖垫图像素传递正确文字。

### 9.2 尺寸优先级

尺寸优先级为：用户指定的精确像素 > 用户指定的比例或用途 > 源图自适应尺寸。普通三种模式不再套用固定默认比例。

四端壁纸没有静默尺寸默认值。若用户明确选择“常用设备预设”，使用手机 1440×3200、iPad 2048×2732 竖版、电脑 3840×2160、儿童手表 1024×1024；也可逐设备自定义。未标注设备的单个尺寸不得擅自套给四张壁纸。

### 9.3 分开准备资产

不要让作图模型一次生成两个区域。先用脚本规划准确尺寸，再分别准备：

- 上下双联：摄影面板适配上半格，版画面板适配下半格。
- 左右双联：摄影面板适配左半格，版画面板适配右半格。
- 纯设计版：只生成一张与最终画布完全同尺寸的版画，不是先生成旧下半格再放大。
- 四端壁纸套装：为四种设备分别生成一张与目标画布同尺寸、同宽高比的变化版画。`INDEPENDENT` 四张分别从原照片求解；`LINKED` 先验收定调图，再让另外三张同时参考原照片＋同一定调图。两种关系都共享同一主体与 016 风格 DNA，并按设备重新求解构图、锚点位置、运动场走向和安全区。

第四至第八节全部作用于变化版画。锚点尺度和 60%–78% 留白都按变化版画自身的完整画框计算。版画资产内部不得出现额外照片、分界线、相框或给照片预留的空间。

### 9.4 模式传递块

在生成提示词末尾附加：

```text
OUTPUT MODE: TOP_BOTTOM | LEFT_RIGHT | DESIGN_ONLY | WALLPAPER_PACK
DEVICE PROFILE: NONE | PHONE | IPAD | DESKTOP | WATCH
FINAL SIZE: <准确 WIDTHxHEIGHT>
DESIGN FRAME: <准确 WIDTHxHEIGHT>
SOURCE VISIBILITY: UPPER PANEL | LEFT PANEL | REFERENCE ONLY — NOT VISIBLE
LAYOUT RULE: 变化版画铺满 DESIGN FRAME；不得在版画内部额外生成照片、分界线、边框或预留区。
WALLPAPER RULE: 有设备配置时，为当前宽高比重新构图；系统 UI 区域保持低信息，关键主体留在安全区；不得画入假时钟、图标、Dock、控制器或设备样机，也不得裁切其他设备的壁纸来冒充本图。
WALLPAPER RELATIONSHIP: NONE | INDEPENDENT | LINKED
ANCHOR DEVICE: NONE | PHONE | IPAD | DESKTOP | WATCH
REFERENCE ROLE: SOURCE ONLY | SOURCE CONTENT + ANCHOR VISUAL DNA
```

### 9.5 壁纸安全区

- **手机**：顶部时钟、刘海或灵动岛区域与底部控制区保持安静，不放锚点核心或精细文字。
- **iPad**：关键内容放在居中安全正方形内，外围只延展纸底、留白和可裁切运动场，使横竖屏裁切都能成立。
- **电脑**：顶部菜单栏、底部 Dock / 任务栏和左右图标边缘保持低信息，不把关键轮廓贴边。
- **儿童手表**：主要轮廓和简化后的文字层级在缩略尺寸下仍需可辨认，并避开主要时间与功能控件区；可以放大、缩短和重新排列文字，但不得默认删除。为保证小屏可读，锚点可放大至画框宽度的 24%–40%，其他一锚点、一运动、留白、配色、排版和印刷质感规则不变。

### 9.6 边界

- 上下双联使用水平中央边界；左右双联使用垂直中央边界。两者都必须干净、直接、无阴影。
- 不使用撕纸、相框、白边、卡片、胶带、扫描边、拼贴阴影或样机。
- 纯设计版没有边界，也不模拟双联结构。
- 四张壁纸同样没有边界，不出现设备框、系统 UI 或多图排版。
- 双联中的少量颗粒呼应不得遮挡或污染摄影主体。

## 十、输出限制

- 每张照片对每个所选普通模式输出一张独立成品；若选择四端壁纸则再输出四张独立壁纸。“全部”严格输出七张 PNG，并分别保存在上下、左右、纯设计、壁纸四个同级任务文件夹中。多张照片仍逐张隔离处理，绝不拼接或制作系列总览。
- 文字严格服从生图前确认：自动或自定义文案包含一个清楚的主标题与最多 2–4 组微型文字；自定义文案未提供微型文字时可专业补写同一语义系统，也可按用户要求只保留主标题。无文字模式不得出现任何字母、汉字、数字或装饰性伪文字。
- 不输出分析文字、创作说明、标题候选或参数列表，只输出成品图。

严格避免：

照片重画、场景重建、可见的生成式扩图痕迹、滤镜感、海报化照片、矢量化描摹、完整插画、信息图表、通用图标、多重焦点、复杂场景、装饰堆积、普通渐变、CG 光效、3D 质感、商业海报感、模板感、多种运动特效叠加、居中对称的呆板构图，以及源照片与变化版画之间失去身份呼应。

## 十一、生成前自检

在提交每一张照片的生成请求前，内部确认：

1. 当前调用只处理一张明确照片，没有携带其他输入的主体、颜色或文案；
2. 所选模式集合与各自尺寸已按第九节锁定，精确像素优先；双联模式沿正确轴严格 50/50，源图隐藏模式没有分界；
3. 双联中的摄影面板仍是真实原照片；单画面和壁纸中不出现原片、分界线或预留区域；
4. 变化版画只有一个可辨认锚点和一种源自照片的运动逻辑，并按自身完整画框保留 60%–78% 留白；
5. 色盘只有一个源自主照片的主色、纸色和可选少量黑；
6. 文案模式已按第八节确定：已按生图前确认锁定自动文案、自定义文案或无文字；目标地区按“受众地区 > 成品语言 > 方向语言；以上均未明确时，生图前询问”解析且不从人物身份猜测；自动或方向型文案使用目标地区的自然语言，由可见事实通向有依据的潜台词、通过换图测试且没有强行玩梗，用户最终成稿逐字保留并按该语言的语义词组排版；主标题层级清楚，只有用户明确要求无字时才完全关闭；
7. 已实际打开成品，以正常尺寸和缩略图检查；锚点、运动、色盘和文案都只属于当前源照片，不是通用装饰抽象；
8. 壁纸套装的四张图分别重新构图、尺寸准确、关键内容位于设备安全区，且没有画入系统 UI；`INDEPENDENT` 四张均只参考原照片，`LINKED` 已先验收定调图且另外三张都直接参考原照片＋同一定调图，没有串联漂移或机械改尺寸；
9. 成品是 Codex 生图产生的 PNG 位图，不是 SVG、HTML、Canvas 或程序化绘图；
10. 没有拼贴、第二焦点、渐变、CG 光效、logo、水印、UI、样机或其他禁止项。
