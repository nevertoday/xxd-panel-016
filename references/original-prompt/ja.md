# XXD Panel 016 原始プロンプト · 日本語訳

> 閲覧用の忠実な翻訳です。実行時の唯一の基準は[簡体字中国語の原文](zh-CN.md)です。

アップロードした各写真を、それぞれ1枚の独立したハイエンドなデザインポスターにしてください。複数画像を組み合わせず、各写真を個別に出力します。全体は3:4の縦構図を採用し、上下2つの領域の高さは厳密に1:1とし、それぞれ画面の50%を占めます。

上半分には元の写真を残し、被写体の構造、リアルな質感、自然な光と影、元の色彩の雰囲気を維持し、わずかにハイエンドな写真のカラーグレーディングのみを施して、アート雑誌、インディペンデント出版物、展覧会写真のような質感を持たせます。画面比率に合わせるため、空、地面、または環境の背景を自然に拡張できますが、被写体を引き伸ばしたり、歪めたり、変更したりしてはいけません。

下半分では、写真の中で最も識別性の高い**被写体、輪郭、姿勢、物語上の関係性**を抽出し、シュルレアリスム的なミニマル版画のビジュアルとして再構成します。被写体を明確で抑制の効いた一つの視覚的アンカーへと圧縮し、通常は広大な余白の中に小さなスケールで配置して、最も重要な輪郭と姿勢だけを残します。複雑なディテールを再現するのではなく、元画像の動き、方向、光と影、または空間関係を、被写体を中心に展開する**動的フィールド**へと変換します。

動的フィールドには、被写体自体の特徴に応じて一つの主要な運動ロジックを自然に選びます。上から下へ落下する、縦方向に上昇する、ある方向に沿って流れる、中心から外へ拡散する、または不規則な波紋と反響を形成するといった動きが可能です。大量の細線、途切れた軌跡、粗い網点、粒子密度の変化で動きを表現し、中心付近はより密に、より強く、縁に向かうにつれて徐々に疎らに、断片的になり、余白の中へ消えていくようにします。複数の効果を同時に積み重ねることは避け、**一つの被写体、一つの動き、一つの巨大な空間関係**を画面の核とします。

上の写真から**最も識別性が高く、最も生気のある一つの主色**を抽出し、暖白、アイボリー、または自然な紙色と少量の黒を組み合わせた厳密な2–3色の体系を構成します。主色は適度に純化して強めることができ、鮮明で力強くしながらも過度にデジタルな印象にはしません。通常のグラデーションではなく、網点密度、インクの重ね刷り、紙面の余白によって濃淡を形成します。シルクスクリーン印刷、Risograph、粗い粒子、紙の繊維、インク被覆のむら、わずかな見当ずれを残し、CG、3D、写実的な光の効果、滑らかなデジタルイラストの質感は避けます。

文字は、抑制の効いた**実験的アートブックのマイクロタイポグラフィシステム**を構築します。写真の動き、距離、状態、感情、または比喩からごく短いタイトルを抽出し、2–4組の極小文字を組み合わせます。短い文、状態語、場所または対象の情報、通し番号、座標風の数字、方向語、アーカイブラベル、観察注記を自由に組み合わせることができます。文字は地平線、動的な軌跡、被写体の軸線、または余白の縁に沿って配置でき、縦組み、回転、広い字間、粒子フィールドへの埋め込み、線がわずかに文字を横切る表現も可能です。これにより、タイポグラフィ自体が空間と動きに参加し、画面上に独立して貼り付けられたものにならないようにします。

全体として、**極小の被写体、極大の余白、強烈なスケールの対比、単一の動的フィールド、粗い印刷の質感**を追求し、静かで、孤独で、神秘的で、詩的かつわずかにシュルレアリスムを帯びた実験的なエディトリアルビジュアルを表現します。被写体が人物、動物、植物、建築、器物、乗り物、自然景観のいずれであっても、写実写真と下部の抽象的なフィールドとの間に明確なアイデンティティの呼応を保ち、複雑な場面、複数の焦点、装飾の堆積、一般的なグラデーション、商業ポスター感、テンプレート感は避けます。
