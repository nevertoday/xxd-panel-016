> 하나의 주제 · 하나의 움직임 · 넓게 숨 쉬는 여백

XXD Panel 016은 Codex와 호환 에이전트를 위한 이미지 생성 Skill입니다. 사진 위에 고정된 필터를 씌우지 않습니다. 피사체, 자세, 방향, 빛, 거리, 아직 끝나지 않은 관계를 읽고, 그 근거를 절제된 촉감의 리소그래프 또는 실크스크린 구성으로 압축합니다.

사진은 사실을 제공하고, 016은 그중 어떤 움직임을 남길지 결정합니다.

## 왜 만들었나요

일반적인 스타일 변환은 서로 다른 사진을 같은 장식 포스터처럼 만들기 쉽습니다. 실제 피사체는 흔한 태양, 파도, 고리, 기하 도형으로 바뀌고, 색은 원본과 무관해지며, 제목은 어느 이미지에 붙여도 통하는 문구가 됩니다.

016은 반대로 작동합니다. 작지만 알아볼 수 있는 시각적 중심 하나를 고정하고, 자세·빛·공간 관계에서 정확히 하나의 움직임 논리를 끌어냅니다. 결과는 미니멀할 수 있지만, 반드시 이 사진에서만 나올 수 있는 근거를 간직해야 합니다.

```text
원본 사진 → 시각적 사실 고정 → 관계와 함의 읽기 → 하나의 움직임 선택 → 판화 생성 → 합성과 검수
```

## 016의 시각적 원칙

- **하나의 중심:** 작고 알아볼 수 있는 핵심만 남기며, 경쟁하는 두 번째 주제를 만들지 않습니다.
- **하나의 움직임:** 낙하, 상승, 흐름, 방사, 파문/메아리 중 하나만 사용하며 효과를 겹겹이 쌓지 않습니다.
- **능동적인 여백:** 보통 종이의 60%–78%를 비워 정적과 움직임이 함께 존재하게 합니다.
- **원본에서 가져온 색:** 원본의 주조색 하나, 따뜻한 종이색, 필요할 때만 검정을 더해 총 2–3색으로 구성합니다.
- **물리적인 인쇄 감각:** 망점, 섬유, 마른 잉크, 입자, 미세한 어긋남을 장식이 아닌 구조로 사용합니다.
- **공간으로서의 타이포그래피:** 제목과 마이크로카피는 광고 박스 안에 놓이지 않고 움직임, 축, 여백을 따릅니다.

## 네 가지 출력, 네 가지 템플릿이 아닙니다

네 가지 모드는 하나만 또는 여러 개를 함께 선택할 수 있습니다. `1`, `1+3`, `1、2、4`, `전체`라고 답하면 Skill이 중복을 제거하고 1→4 순서로 실행합니다. 각 모드는 별도 작업 폴더에 독립적으로 출력되며 한 장의 모음 이미지로 합치지 않습니다. `전체`는 원본 한 장당 PNG 7개(일반 모드 각 1개＋배경화면 4개)를 만듭니다. 크기는 모드별로 표시해 같은 답변에서 지정할 수 있고, 지정하지 않은 일반 모드는 원본에 맞춥니다. 문구는 기본적으로 선택한 모드가 공유하며 모드별 지정도 가능합니다.

| 모드 | 크기 규칙 | 결과물 |
| --- | ---: | --- |
| `top-bottom` | 원본 적응형 | 위에는 원본 사진, 아래에는 016 판화. 각 패널이 원본의 전체 크기를 유지하며 정확히 50/50으로 나뉩니다. |
| `left-right` | 원본 적응형 | 왼쪽에는 원본 사진, 오른쪽에는 016 판화. 각 패널이 원본의 전체 크기를 유지하며 정확히 50/50으로 나뉩니다. |
| `design-only` | 원본 적응형 | 원본 사진은 보이지 않고 변환된 판화 한 장만 출력합니다. 원본 비율과 크기를 유지합니다. |
| `wallpaper-pack` | 기기별 네 가지 크기 | 휴대전화, iPad, 데스크톱, 어린이용 스마트워치 PNG를 각각 출력합니다. |

짝을 이루는 모드의 사진은 절제된 색 보정과 필요한 범위의 환경 확장만 적용해 사실성을 지킵니다. 디자인 단독 및 배경화면 모드에서는 사진이 근거로만 쓰이고 완성 이미지에는 나타나지 않습니다.

### 배경화면 세트: 독립형 또는 연결형

배경화면 세트에는 몰래 적용되는 기본 크기가 없습니다. 일반 기기 프리셋인 휴대전화 `1440×3200`, iPad `2048×2732`, 데스크톱 `3840×2160`, 스마트워치 `1024×1024`를 선택하거나 기기명을 붙인 사용자 지정 크기를 입력합니다.

- **연결형 세트(권장):** 먼저 iPad 기준 작품을 생성해 승인합니다. 나머지 기기에는 원본 사진과 승인된 동일 기준 작품을 함께 참조로 주고, 각 캔버스에 맞게 새로 구성합니다.
- **독립형 세트:** 각 기기는 원본 사진만 참조하며 더 자유롭게 탐색할 수 있습니다.

두 방식 모두 네 개의 독립 파일을 반환합니다. 연결형은 하나의 기준 이미지를 네 번 잘라 쓰지 않으며, iPad→휴대전화→데스크톱→스마트워치처럼 참조를 연쇄적으로 전달하지도 않습니다.

## 문구는 사진을 다시 보게 해야 합니다

생성 전에 자동 문구, 사용자 지정 문구, 무문자 출력 중 하나를 선택합니다. 앞의 두 경우에는 목표 언어나 지역도 함께 정합니다. 사용자 지정 문구에는 정확한 제목과 선택적 마이크로카피를 입력할 수 있습니다.

자동 문구는 눈에 보이는 사실, 관계의 긴장, 근거 있는 함의를 읽습니다. 그런 다음 정확한 명명, 대비, 절제, 중의성, 가벼운 반전을 통해 매우 짧은 제목을 만듭니다. 제목은 ‘무관한 이미지 교체 테스트’를 통과해야 합니다. 다른 사진에도 똑같이 잘 어울린다면 다시 써야 합니다.

사용자가 완성 문구를 주면 그대로 유지합니다. 방향이나 수정 가능한 초안일 때만 대상 독자, 전달 목적, 필수 단어, 어조, 함의를 보존한 채 다듬습니다.

언어는 명령을 작성한 언어가 아니라 의도한 독자를 따릅니다.

```text
목표 시장 또는 독자 > 지정한 출력 언어 > 지시문 언어; 모두 불분명하면 생성 전에 질문
```

중국어로 요청해도 일본 시장판이면 자연스러운 일본어를 사용합니다. 한국 독자용이면 자연스러운 현대 한국어와 정확한 띄어쓰기를, 영국판이면 영국 영어를, 아랍어판이면 자연스러운 현대 표준 아랍어와 실제 오른쪽에서 왼쪽으로 흐르는 구성을 사용합니다. 인물의 얼굴이나 장면만 보고 국적을 추측하지 않으며, 분위기를 위해 가짜 외국어 문자를 쓰지 않습니다.

## 정확한 기하는 코드가, 미술 방향은 이미지 생성이 맡습니다

이미지 모델이 판화를 생성합니다. `scripts/compose_panel.py`는 캔버스 계획, 정확한 50/50 래스터 합성, 최종 크기 확정, 결과 검수만 수행합니다. 프로그램 도형으로 작품을 위조하지 않습니다.

```bash
python3 scripts/compose_panel.py --plan --layout top-bottom --source photo.png
python3 scripts/compose_panel.py --plan --layout left-right --size 2560x1440
python3 scripts/compose_panel.py --audit result.png --layout design-only --size 2048x2048
```

정확한 상하 캔버스는 전체 높이가 짝수여야 하고, 좌우 캔버스는 전체 너비가 짝수여야 합니다. Skill은 요청한 픽셀 크기를 몰래 변경하지 않습니다.

## 경계와 신뢰

- 각 원본 사진은 자기 작업 안에만 머물며 다른 피사체, 과거 결과, 번들 예시를 빌리지 않습니다.
- 호출할 때마다 새 작업 폴더를 만들며 이전 결과를 이번 작업의 완성품이라고 선언할 수 없습니다.
- 결과물은 PNG 비트맵이며 SVG, HTML, Canvas, 프로그램 벡터 대체물이 아닙니다.
- 설정된 비트맵 브리지는 정제된 상태만 출력하며 공급자, 엔드포인트, 헤더, 인증 정보, 프롬프트, 서버 응답 본문을 노출하지 않습니다.
- 선택한 일반 모드마다 파일 1개를 반환하고, `wallpaper-pack`을 선택하면 독립 배경화면 4개를 추가합니다. `전체`는 원본 한 장당 PNG 7개를 네 개의 동급 모드 폴더에 저장하며 모음 이미지로 합치지 않습니다.

로컬 합성에는 Python 3와 Pillow가 필요합니다. 안전한 비트맵 브리지는 Python 3.11 이상의 `tomllib`을 사용합니다. 이미지 생성에는 내장 래스터 생성 기능이 있는 호스트 에이전트 또는 이미 설정된 호환 래스터 경로가 필요합니다.
